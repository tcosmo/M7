## 4. Interpretation System

Built end-to-end interpretation preselection and synchronization.

- `m_preselectedInterpretation`: set by thumbnail click, used when entering a level
- `loadSources()` uses preselected index instead of hardcoded 0 for: YouTube URL, tuning, beats, volume, start/end times

- Changing interpretation in sidebar combo syncs `m_preselectedInterpretation` back to level browser
- Resume with changed interpretation triggers full level reload
- Navigating back to browser restores correct thumbnail selection

## 5. YouTube Video UX Overhaul

Established strict rules for YouTube interaction after extensive debugging of auto-play issues.

### Core Rule
**Never call pause(), seekTo(), or play() on YouTube unless the user explicitly presses Play.**

### Implementation
- `loadYouTube()` same-URL path: returns immediately, no touch
- `videoReady` handler: only resizes iframe, no pause
- `loadLevel()`: sets `m_needsSeekOnPlay = true`, does NOT touch YouTube
- `playerPlay()`: ONLY place that calls seekTo + play; clears m_needsSeekOnPlay first
- `playbackStarted` handler: updates UI, seeks to interpStart if needed
- Toolbar seek slider and time label reset to 0:00 on level entry

### Other Video Fixes
- Video container: 220x200 (YouTube ToS minimum 200x200)
- Keyboard isolation: QWebEngineView + all child widgets set to Qt::NoFocus
- `--no-proxy-server` Chromium flag to suppress WPAD errors
- Iframe resize forced on collapse/expand/load to prevent size mismatch
- Spacebar in navigation view directly toggles YouTube play/pause
- "Collapse" renamed to "Minimise Video", styled as proper button with left margin

## 6. Crash Fixes

- **ScoreWidget::resizeEvent dangling pointer**: Call `m_scoreWidget->setEngine(nullptr)` before `m_engine.reset()` in `loadScore()` to clear ScoreCanvas's raw pointer to the destroyed engine
- **ensureWidgetVisible crash**: Use target card widget as QTimer context object so callback auto-cancels if widget is destroyed by rebuild()
- **ScoreWidget::resizeEvent null guard**: Added null checks for m_triggerOverlay and m_canvas
